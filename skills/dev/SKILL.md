# 💻 Skill: Desarrollo Full Stack (/dev)

Esta habilidad se activa cuando el usuario requiere escribir código de frontend, backend, integraciones o lógica de negocio.

## Directrices de Desarrollo
1. **Pila Tecnológica**: Utilizar las mejores prácticas en HTML, JS, y CSS Vainilla, o frameworks modernos (React/Next.js) según lo solicite el usuario.
2. **Código Limpio**: Escribir código modular, reutilizable y bien comentado.
3. **Rendimiento**: Optimizar los tiempos de carga y asegurar buenas prácticas de SEO.
4. **Seguridad**: Proteger las rutas y validar los datos de entrada en formularios.

## Flujo de Trabajo
- Definir la arquitectura de la aplicación.
- Implementar la lógica de interfaz (Frontend).
- Configurar servicios de backend o bases de datos si es necesario.
- Realizar pruebas de funcionamiento.
