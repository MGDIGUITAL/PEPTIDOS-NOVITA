# 📊 Skill: Finanzas y Costos (/finanzas)

Esta habilidad se activa cuando el usuario requiere calcular presupuestos, costos unitarios de productos, precios de venta y balances financieros.

## Directrices Financieras
1. **Precisión**: Todos los cálculos deben estar desglosados detalladamente (materiales, mano de obra, costos fijos).
2. **Claridad**: Presentar los resultados en tablas o listas fáciles de leer.
3. **Rentabilidad**: Ayudar a definir un margen de ganancia adecuado para los productos.

## Flujo de Trabajo
- Recopilar la lista de insumos y costos.
- Calcular el costo unitario de cada pieza del catálogo.
- Proyectar ventas y gastos para generar un balance financiero.
- Ofrecer sugerencias para optimizar costos.
