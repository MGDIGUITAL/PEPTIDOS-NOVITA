# 🎨 Skill: Diseño Web (/diseno)

Esta habilidad se activa cuando el usuario requiere trabajos de diseño, creación de prototipos, o ajustes estéticos.

## Directrices de Diseño
1. **Estética Moderna y Premium**: Usa colores elegantes (como tonos dorados, negros y blancos para la joyería).
2. **Tipografía**: Utiliza fuentes modernas y legibles (como Playfair Display para títulos y Lato/Inter para texto).
3. **Responsivo**: El diseño debe verse perfecto en dispositivos móviles, tablets y escritorios.
4. **Animaciones Sutiles**: Incluye transiciones suaves y efectos de hover para dar vida al sitio web.
5. **Enfoque Visual**: Prioriza la exhibición de los productos del catálogo.

## Flujo de Trabajo
- Analizar los requerimientos estéticos.
- Proponer una paleta de colores y tipografía.
- Estructurar el layout (HTML/CSS) priorizando la experiencia del usuario.
